Network

Proxy Service

Rides the bungeecord:main plugin-messaging channel — works against BungeeCord and Velocity's built-in compatibility layer with no proxy-side plugin required.

Backend Servers

One server name per line, matching the proxy's own configured server names exactly. The network-wide total is always polled regardless of this list.

Network Stats

Lets this hub read player stats from other servers over HTTP via each one's SwagCore, without connecting directly to their databases. Test with /ah networkstats <server> <player>.

Known Servers

Server id → full URL to that server's SwagAPI network-service mount (e.g. http://10.0.0.180:8080/swagnet/swagcore/).

Messages

Every value is parsed as MiniMessage (hex colors, gradients, and legacy-style tags are all supported). prefix is prepended automatically to messages sent through the plugin's message util.
